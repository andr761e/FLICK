# Practice Packs // focus artwork

Generated on 2026-10-23 using the built-in image-generation tool. Full-bleed decorative card illustrations, not gameplay screenshots. All labels, scores, selection edges and interactions are native Slate. The generated art does not change gameplay geometry or lighting.

References: `Deliverables/UI-Visual-Upgrade-2026-10-22/Concepts/08-practice-packs-v2.png` (style/composition); `AssetDevelopment/UI/PuckThumbnails/Presentation/Standard_0.png` (actual puck model); the BOB image additionally references `AssetDevelopment/UI/MenuArtwork/PracticeBob.png` (board palette).

Final masters are stored in this directory: `PracticePrecisionV3.png`, `PracticeKnockoutsV3.png`, `PracticeSwitchV3.png`, `PracticeBobV3.png` (1672 × 941). Import with the existing Unreal Python commandlet and `Tools/Import-FlickMenuArtwork.py -FlickPracticeArtwork`. Runtime assets use BC7, sRGB, UI texture group, streamed mips and a 1024 maximum size; existing menu art is retained.
