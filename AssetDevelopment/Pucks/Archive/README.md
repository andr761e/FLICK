# Archived puck work

This folder contains superseded development packages retained for recovery and
historical reference. Nothing here is consumed by the current import pipeline.

- `LegacyWorkshop/` — the old generated workshop, exports, renders and backups.
- `LegacyPackageLayout/` — leftover files from the original high-detail package
  layout, including duplicate Heavy outputs and superseded setup notes.

Do not generate or import production assets from this directory.
