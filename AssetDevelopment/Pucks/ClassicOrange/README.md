# Classic Orange

This cosmetic set uses the nine meshes in `../ClassicBlue/exports/` and their
neutral graphite/silver materials. Its independent orange diffuser and emblem
colours are authored in `set.json`, not generated by changing the Blue FBXs.

Run `.\update-flick-pucks.cmd` from the project root after changing either set.
The importer reads this configuration and updates the two existing Orange
material instances. No duplicate FBXs or player-number variants are needed.
